# README

Algunas instrucciones para la instalación de la aplicación.

## Instalación

### Instalación de action_text
```
rails action_text:install
```

### Agregar funcionalidad por js

Esto agrega la línea pin "local-time" # @3.0.2 al archivo *importmap.rb*
```
bin/importmap pin local-time
```


# Creación de la base de datos
```
rails db:create
```

# Authentication creation
```
rails g authentication
```
